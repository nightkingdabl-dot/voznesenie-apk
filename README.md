# Вознесение — v0.2

Игровое ядро прототипа.

## Реализовано
- 3D игрок и движение
- камера
- базовый бой
- враги
- здоровье и энергия
- элемент «Пепел»
- элементальный навык
- интерактивная древняя плита
- противоречивый фрагмент истории
- репутация
- флаги мира
- найденные сведения
- JSON-данные лора
- сохранение/загрузка
- Android-oriented рендеринг
- GitHub Actions для сборки

## Управление в редакторе
WASD — движение
SPACE — атака
Q — элементальная способность
E — взаимодействие

## Важно
Для полноценного APK-профиля в GitHub/Godot могут потребоваться Android export templates и настройки подписи. Workflow является стартовой автоматизацией сборки; release signing лучше добавить отдельно перед публикацией.
